# Animation & Motion Graphics SOP

Stage 5B of the short-form editing workflow: Story Structure → Cutting & Pacing → Music → Color Grading → **Stage 5: Effects & Animation (5A Transitions, Zoom & Masking via `video-transitions-zoom-masking` → 5B Animation & Motion Graphics, this skill)** → Subtitles & On-Screen Text → Sound Design & Final Mix → Final QC. Use it to decide **what to animate, how, and when** for any video, and to produce an animation plan the editor can execute.

**Division of work with 5A:** basic transitions (cuts, J/L-cuts, match cuts, whips, dissolves), zoom in/out and masking of people, backgrounds and objects are planned in 5A. This skill takes 5A's Effects Plan as input, builds on it (e.g. reuses a subject mask for text behind the person, adds a graphic to a zoom-out reveal) and does not redo or add competing transitions/zooms. Graphic and shape transitions, kinetic text, logos, labels and other motion graphics are planned here. If 5A was skipped, do a quick purpose check on any transition/zoom/mask yourself and keep it simple.

Reply in the user's language. If they write in Taglish, answer in Taglish.

## Core rules

1. **Every animation must have a purpose.** If it doesn't serve emphasis, explanation, direction, integration, engagement, brand expression or storytelling, don't add it. If removing it makes the video better, remove it.
2. **Analyze the video type first.** Before choosing any style, classify the video (Step 2). The type decides the default intensity, techniques and timing feel. Do this yourself from the footage, transcript, story map or description; only ask when the material truly doesn't show it.
3. **Reference first.** When a reference exists, match its movement, timing, easing, typography and graphic treatment. Never impose a familiar or easier style over it.
4. **No reference = deliberate creative direction, not random effects.** Build the direction from the video type, content objective, brand identity, footage and audience (Step 3B).
5. **Footage and story come first.** Animation must never cover the subject, the product details, faces or important information, and must never fight the pacing set in the trim phase, the look set in color grading, or the transitions/zooms/masks set in 5A.
6. **Readability over decoration.** Text must stay on screen long enough to read and inside platform safe zones.
7. **No fixed presets.** Presets are tools; the final execution must fit this project.
8. **Be honest about limits.** If the reference can't be matched (missing assets, software, footage), say so and offer the closest achievable alternative. Never silently swap the style.

## STEP 1: Gather inputs

Use what the user already gave. Ask only for what's missing and actually needed, in one message:

- **The video:** footage, rough cut, frames, transcript/SRT, story map from the storytelling phase, or a description of the scenes.
- **Effects Plan from 5A (if done):** transitions, zooms and masks already planned, so animation lines up with them.
- **Reference (optional):** a reference video, animation or visual sample. If none, say you'll set the direction yourself (Step 3B); don't block on it.
- **Objective and audience:** sell, inform, entertain, build the brand, tell a story, hype an event.
- **Brand assets:** logo (ideally vector/PNG with alpha), brand fonts, colors, existing motion style if any.
- **Platform and format:** Reels/TikTok/Shorts (9:16), YouTube (16:9), feed (4:5/1:1); duration; frame rate.
- **Software:** After Effects, Premiere Pro, DaVinci Resolve/Fusion, CapCut, Final Cut, other.
- **Text content:** on-screen copy, key words, prices, CTAs, labels.

## STEP 2: Video Type Analysis (always do this)

Classify the video from the material. Write a short **Video Profile**:

- **Primary type** (from the table below) and any **secondary type** for specific sections (e.g. talking head with a product-showcase section).
- **Objective:** what the video must achieve.
- **Tone/energy:** calm, warm, cinematic, playful, energetic, premium, informative.
- **Pacing:** from the trim phase and the Stage 3 Music Plan — cut density, beat-driven or speech-driven, BPM and key music accents.
- **What carries the story:** the speaker, the footage, the music, or on-screen text.
- **Animation load:** Minimal / Light / Moderate / Heavy — how much animation this video can carry without distracting (count 5A's effects toward the total).
- **Evidence:** 1–3 short reasons from the footage or brief for the classification.

If the material is ambiguous, state your best reading and why, then proceed. Don't stop to ask unless the choice would change the whole direction.

### Video type → default animation profile

These are starting points. A reference always overrides them, and the actual footage can push them up or down.

| Video type | Main animation purposes | Default load & intensity | Typical techniques | Avoid |
|---|---|---|---|---|
| **Talking head / vlog / educational** | Emphasis, explanation, retention | Light–Moderate, clean | Keyword pop-ups, kinetic captions on key lines, simple icons/labels, lower thirds, text paired with 5A's zoom-ins | Covering the face/mouth, animating every sentence, text over the speaker's eyes |
| **Tutorial / explainer / how-to** | Explanation, direction | Moderate, clear | Step numbers, arrows, callouts, highlight boxes, diagrams, screen-recording zooms | Decorative motion that slows comprehension |
| **Product showcase / e-commerce** | Direction, emphasis, brand | Light–Moderate, premium | Tracked labels on features, clean graphic reveals, price/CTA cards, mask reveals | Covering product details, cheap bouncy text on premium products |
| **Food / restaurant** | Engagement, emphasis, brand | Light, appetizing | Dish name/price reveals, subtle tracked labels, steam/sizzle accents only if stylistically fitting, end card with location/CTA | Graphics over the hero bite/pour/cheese pull; anything that makes food look less appetizing |
| **Brand video / company profile** | Brand expression, storytelling | Moderate, consistent | Logo animation, branded type system, shape transitions, lower thirds, value statements | Off-brand fonts/colors, inconsistent easing between elements |
| **Storytelling / cinematic / emotional** | Storytelling, atmosphere | Minimal, restrained | Slow fades, soft title reveals, minimal type, gentle parallax | Fast, flashy or playful motion that breaks the mood |
| **Music-driven montage / sports / event highlights / hype** | Engagement, energy | Moderate–Heavy, dynamic | Beat-synced text slams, speed-ramp-matched graphics, shape/flash transitions, scoreboard/stat graphics | Animating every beat; covering the action/peak moments |
| **Lifestyle / BTS / day-in-the-life** | Engagement, light context | Light, casual | Handwritten/sticker-style text, location/time tags, simple pop-ins | Over-polished corporate motion that feels fake |
| **Testimonial / interview** | Credibility, context | Minimal, clean | Name/role lower thirds, pull-quote highlights | Distracting motion while the person delivers emotional lines |
| **Ad / promo / offer** | Emphasis, conversion | Moderate, punchy | Offer/price callouts, countdowns, CTA animation, logo sting | Unreadable fast text; CTA that appears too briefly |

### Mixed videos
Assign a type per section (hook, build-up, payoff, CTA). The hook may carry more motion to stop the scroll; emotional beats may carry less. Keep one shared visual language (font, easing family, color) across sections so it still feels like one video.

## STEP 3A: Reference Analysis (when a reference exists)

Write a **Reference Breakdown**:

1. **Style:** minimal, kinetic, cinematic, playful, 2D/3D, stylized/frame-by-frame, etc.
2. **Movement:** how elements enter, move, interact and exit; direction; scale changes.
3. **Timing & easing:** fast/slow entrances, holds, overshoot/bounce, linear vs. eased, approximate durations in frames.
4. **Typography:** fonts or font class, weights, case, size hierarchy, color, stroke/shadow, how text reveals (per letter, word, line).
5. **Graphic treatment:** shapes, icons, textures, colors, blend modes.
6. **Integration:** tracked or screen-fixed, masked behind subjects, interaction with camera motion.
7. **Audio relationship:** synced to beats, SFX hits, or independent.
8. **Replicate vs. adapt:** what must be matched closely and what can be adapted to the user's assets.
9. **Tools needed:** which software features/techniques achieve it.

End with a one-line **Target Motion Summary**.

**Feasibility check:** if the footage lacks trackable detail, the software can't do it (e.g. 3D in CapCut), or assets are missing, rate it Achievable / Partially achievable / Not realistic, explain briefly, and offer 1–3 closest alternatives. Let the user choose before switching.

## STEP 3B: Creative Direction (when there is no reference)

Build the direction from the Video Profile:

1. **Identify the purpose** of each candidate element: emphasis, explanation, direction, visual integration, engagement, brand expression or storytelling. No purpose → no animation.
2. **Choose the technique for the result**, not because it looks cool (use the type table above as the default).
3. **Set one visual language:** font system, easing family, color, entrance/exit logic. Vary only when elements serve different purposes, and make the variation intentional. Match the transition family chosen in 5A.
4. Write a one-line **Target Motion Summary**, e.g. "Clean, restrained product motion: tracked thin labels, 12-frame ease-out reveals, brand color accents only."

Show the Video Profile and the Target Motion Summary to the user before the detailed plan.

## STEP 4: Animation Plan

Produce an **Animation Plan** table for the whole video:

| # | Time (in–out) | Element | Purpose | Technique | Position / layer | In / hold / out | Easing | Sync |
|---|---|---|---|---|---|---|---|---|
| 1 | 00:00.0–00:01.8 | Hook keyword "…" | Emphasis | Scale-up word reveal | Upper third, above subject | 8f / 1.2s / 6f | Ease-out (fast in) | Beat 1 / SFX whoosh |

Rules for the plan:
- Every row must have a purpose. If you can't write one, drop the row.
- Note what the element must **not** cover (face, product, food, action).
- Mark rows that need tracking, masking or roto so the editor can budget time; reuse masks from 5A where they already exist.
- Flag sections where **no animation** is the right call (e.g. emotional pause, hero shot).

### Timing starting points (adjust to the reference, pacing and footage)
- **Entrances/exits:** energetic ≈ 4–8 frames; standard ≈ 8–14 frames; cinematic ≈ 15–30+ frames (at 24–30 fps).
- **Text hold:** long enough to read twice comfortably — roughly 0.3–0.4 s per word, minimum ≈ 1 s for a short phrase. Never let a CTA, price or key info disappear before it can be read.
- **Easing:** ease-out for entrances, ease-in for exits; overshoot/bounce only for playful types; near-linear only when the reference does it or for continuous drifts.
- **Spacing between animations:** let one element land before the next starts unless the reference stacks them.

### Safe zones (vertical 9:16)
Keep text and key graphics out of the bottom ≈ 20–25% (captions/UI), the right ≈ 12–15% (action buttons) and the top ≈ 10% (profile/header). Reserve the subtitle zone for the subtitles phase (Stage 6, next) so animated text and captions don't collide.

## STEP 5: Execution

- Follow the reference's movement, style and timing when one exists; otherwise follow the Target Motion Summary.
- Apply keyframes, easing, masks, tracking, transitions or other techniques as the plan requires.
- Match movement speed and intensity to the footage motion and cut rhythm.
- Keep alignment, spacing, proportions and readability (contrast, size on a phone screen).
- Adapt to available assets and technical limits; use the closest appropriate alternative and say what changed.
- Don't add effects outside the plan or the reference.

### Possible techniques (options, not a checklist)
Text animation and kinetic typography · logo and brand animation · motion graphics and graphic reveals · tracking-based text/graphic integration · masking and reveals (building on 5A masks) · 2D/3D motion graphics · shape animation and graphic transitions · frame-by-frame or stylized animation · movement-based transitions · subtle or dynamic object movement.

### The user's reference library
When the user gives no reference for this video, use `.agents/skills/my-ai-editor/references/reel-references.md` as the reference for STEP 3A: its
two-tier headlines, giant stat numbers, glass pill lists, callout diagrams over a blurred speaker and full-screen
type cards are the house style. Pick from its technique menu by purpose.

### Tool hints
- **After Effects:** graph editor for easing, text animators, 3D camera tracker / Mocha for tracking, track mattes, shape layers, Essential Graphics templates for reuse.
- **Premiere Pro:** Essential Graphics, keyframes with Bezier easing, mask tracking; send complex shots to AE via Dynamic Link.
- **DaVinci Resolve:** Fusion page (Text+, trackers, masks), Edit-page Text+ and keyframe curves.
- **CapCut:** keyframes with speed curves, text templates (customize, don't use as-is), tracking, masks, overlay layers.

---

## STEP 6: Timing & Integration

- Align each animation with the scene timing in the plan.
- Sync to beats or SFX **only when it improves the result**; for speech-driven videos, sync to the spoken word instead.
- Match animation speed to footage movement and camera motion (tracked elements should inherit motion blur when the footage has it).
- Adjust entrances, pauses, holds and exits to the reference or direction.
- Remove motion where the scene already communicates well.
- Note SFX cues needed for the sound-design phase (whooshes, pops, hits) in the plan's Sync column, but keep them subtle and purposeful.

---

## STEP 7: Justify and Review

For every animation, answer:
1. What is it communicating?
2. Where should the viewer focus?
3. Does it improve clarity, storytelling or visual appeal?
4. Does it fit the brand, the video type and the scene?
5. Would the video be better without it?

Watch key scenes with and without the animation. Revise or remove anything excessive, arbitrary or disconnected. Check on a phone at real size.

---

## STEP 8: Final Quality Control

Mark each item Pass or Fix:
- [ ] The video type was analyzed and the Video Profile matches the content
- [ ] The reference was reviewed, or a clear creative direction was set
- [ ] Every animation serves a specific purpose
- [ ] Movement, timing and easing fit the reference/direction and the pacing
- [ ] Animation works with 5A's transitions, zooms and masks (no doubled or competing effects)
- [ ] Typography and graphics are well positioned, aligned and inside safe zones
- [ ] Nothing covers faces, products, food hero moments or key action
- [ ] Animation integrates naturally with the footage (tracking stable, no sliding, motion blur matches)
- [ ] Music/SFX sync is appropriate where used
- [ ] Visual language is consistent across the video; variations are intentional
- [ ] No unnecessary effects or movements
- [ ] All text is readable on a phone and holds long enough to read
- [ ] Brand assets (logo, fonts, colors) are correct and high quality
- [ ] Technically clean: no jitter, popping keyframes, edge artifacts, aliasing or wrong frame rate
- [ ] Animated text doesn't collide with the subtitle zone
- [ ] Compared side by side with the reference when available
- [ ] Test export checked on the target platform/device

For each Fix, name the plan row and the change, then re-check only that part.

## Common mistakes to avoid
- Choosing a style before analyzing the video type
- Imposing a familiar style over the reference
- Using the same entrance/exit on every element without thinking
- Animating everything because there was no reference
- Text that disappears before it can be read, or sits under platform UI
- Graphics covering the subject, the product details or the hero food shot
- Playful bouncy motion on cinematic, premium or emotional content
- Beat-syncing every element just because there's music
- Using CapCut/AE templates as-is instead of matching the project
- Redoing or stacking transitions, zooms or masks that 5A already planned
- Fighting the pacing from the trim phase or the look from color grading
