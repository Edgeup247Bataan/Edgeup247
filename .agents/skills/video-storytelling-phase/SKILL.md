# Video Storytelling Phase (Stage 1 of the Short-Form Editing SOP)

Use this skill whenever the user wants to plan the story of a video, choose a structure, find a hook or payoff, order clips, or build an edit plan before cutting. This is the first of 8 stages: Story Structure → Cutting & Pacing (video-trim-phase) → Music (video-music-phase) → Color Grading (color-grading-sop) → Effects & Animation (5A Transitions, Zoom & Masking: video-transitions-zoom-masking → 5B Animation & Motion Graphics: animation-motion-graphics-sop) → Subtitles & On-Screen Text (video-subtitles-phase) → Sound Design & Final Mix (video-sound-design-phase) → Final QC (video-final-qc-phase). Hand off to the next stage only after the story map is approved.

Standard duration: 30–60 seconds. It can run longer or shorter when the story needs it.

## RULES (always follow)

1. **Story first, effects second.** Never suggest a transition, effect or trend to fix a weak story. Fix the structure first.
2. **Timings are guides, not limits.** Section windows (hook 0–3s, build-up, etc.) can stretch depending on the clip. Never cut necessary content just to hit a timestamp.
3. **Work from the real footage only.** Base every suggestion on the transcript, shot list, clips or description the user actually gave. Never invent moments, quotes, reactions or shots that don't exist. If something is missing, flag it as a missing shot instead of pretending it's there.
4. **Every clip needs a job.** Each selected clip must be labeled with its purpose (hook, context, build-up, payoff, resolution, mood, detail, B-roll). A clip with no job is cut or marked optional.
5. **Don't follow recording order by default.** Order clips by viewing experience, not by when they were filmed.
6. **The payoff must justify the wait.** Only delay a reveal if the payoff is strong enough. If it's weak, show it earlier or pick a different structure.
7. **Hook must be real and honest.** The hook must be a moment that exists in the footage and must be paid off later. No clickbait that the video doesn't deliver.
8. **Preserve authenticity.** Don't restructure in a way that misrepresents what happened, what a person said, or what a product does.
9. **Combine frameworks only with reason.** Max 2–3 frameworks, and only when they serve the same objective. Say why they're combined.
10. **Ask before guessing on the objective.** If the content objective or target audience isn't clear and it would change the structure, ask one short question first. If the footage is clear, proceed.
11. **Keep pauses that carry emotion.** Pauses with facial expression or reaction that help the viewer connect are story moments, not dead air.
12. **Output a story map before moving to cutting.** Stage 2 doesn't start until the story direction is clear.

## WORKFLOW

### Step 1: Identify the content objective
Pick the primary purpose: tell a personal/brand story, showcase a product/service, capture an event/experience, communicate information, create an emotional connection, or present a brand mood montage. Also note the platform (Reels/TikTok/Shorts), the audience, and the one thing the viewer should feel or remember.

### Step 2: Review and organize the footage
From the transcript, shot list, timestamps or description, identify:
- strongest opening moment (hook candidates)
- key actions and information
- reactions and emotional moments
- most visually appealing shots
- the main reveal or payoff
- the strongest possible ending
- missing shots that the story needs

### Step 3: Select the storytelling structure

| Code | Framework | Best for |
|---|---|---|
| A | Hook → Context → Build-up → Payoff → Resolution | general storytelling, BTS, creator content |
| B | Problem → Agitation → Solution | product, service, marketing (only if a real problem exists) |
| C | Before → After → Bridge | transformations, food prep, makeovers, process |
| D | Three-Act (Setup → Development → Resolution) | personal stories, mini-docs, brand stories |
| E | Open Loop → Delayed Reveal | curiosity, interviews, product reveals |
| F | Journey → Discovery → Realization | lifestyle, travel, reflective |
| G | Question → Exploration → Answer | educational, reviews, explainers |
| H | Emotional Build → Climax → Release | celebrations, reunions, community, event recaps |
| I | Music-Driven Aesthetic Montage | cafés, restaurants, product, brand mood |
| J | In Medias Res → Context → Resolution | action, event highlights |
| K | Observation → Detail → Experience | ambience, craftsmanship, routines |
| L | Character → Motivation → Action → Change | founder, customer, staff, creator profiles |

Suggested timing for A (flexible): Hook 0–3s, Context 3–10s, Build-up 10–30s, Payoff 30–45s, Resolution 45–60s.

Common combos: Product = Hook + Before/After + Montage. Personal story = Open Loop + Three-Act. Café = Montage + Observation/Detail. BTS = In Medias Res + Before/After. Event recap = Emotional Build/Climax/Release.

### Step 4: Establish the narrative flow
Verify: the opening grabs attention or sets the mood; the sequence develops logically or visually; key moments are easy to understand; the ending feels intentional; every clip serves the objective.

## WHAT CLAUDE CAN DO IN THIS PHASE

- **Footage breakdown:** Turn a transcript, SRT, shot list or clip description into a tagged inventory (clip, timestamp, content, emotion, strength 1–5, possible role).
- **Hook finder:** Rank the top 3 hook candidates from the actual footage, with the reason each would stop the scroll, and say which payoff each hook promises.
- **Structure recommendation:** Suggest the best 1–2 frameworks with a one-line reason, plus an alternate structure if the footage supports a different angle.
- **Story map:** Build the ordered sequence with section, clips, target time range, purpose, and notes (see output format).
- **Payoff check:** Confirm the payoff exists and is strong enough; if not, suggest reordering or a different framework.
- **Missing shot list:** List shots the story needs but the footage lacks (e.g. reaction, establishing wide, product close-up, ending shot) so the user can reshoot or substitute B-roll.
- **Cut-for-story list:** Flag clips that don't serve the objective as cut or optional.
- **Opening line / on-screen text ideas:** Draft hook text or caption lines that match what is really in the footage (final wording and styling are done in Stage 6).
- **Retention walk-through:** Point out where viewers might drop off (slow context, repeated info, delayed payoff) and suggest a fix that keeps the story intact.
- **Ending options:** Suggest 2 ending choices (callback to hook, emotional beat, CTA, musical resolution) based on the objective.
- **Duration estimate:** Estimate total runtime from the story map and say if it goes past 60s and whether that's justified.

## OUTPUT FORMAT

1. **Objective** – one line (purpose, audience, what they should feel/remember).
2. **Chosen structure** – framework code(s) + why.
3. **Hook options** – top 3, recommended one marked.
4. **Story map** – table:

| # | Section | Clip / timestamp | Target time | Purpose | Notes |
|---|---|---|---|---|---|

5. **Cut or optional clips** – with reason.
6. **Missing shots** – if any.
7. **Estimated duration** – and whether timing stretches are justified by the story.
8. **Ready for Stage 2?** – yes/no and what still needs a decision. For a music-driven montage or a video built around a given track, say so: pick the track first with Stage 3's music-first mode, then cut to it in Stage 2.

Keep the output scannable. If the user only asks for one part (e.g. just hooks), give just that part.
